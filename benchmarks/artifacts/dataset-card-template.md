# Bifrost FiQA benchmark embeddings

This dataset stores precomputed embeddings used by Bifrost's reproducible HNSW
competitor benchmark. It contains derived vectors, stable record identifiers,
and the FiQA test relevance judgments needed to evaluate semantic retrieval.

The 384-dimensional and 1536-dimensional fixtures are generated by independent
embedding requests. The 384-dimensional fixture is not produced by truncating
the 1536-dimensional output.

## Integrity and reproduction

`manifest.json` records the byte length and SHA-256 checksum of every fixture
file. Consumers must pin an immutable 40-character Hub commit and validate the
manifest and every listed file before benchmarking. Network access is not part
of a benchmark run.

## Limitations

These embeddings are a derived benchmark artifact, not a general-purpose FiQA
release. Results depend on the recorded model, requested dimensions,
preprocessing, normalization checks, and exact source snapshot. Model behavior
can change across provider revisions even when a public model name remains the
same.

## Publication review

Publishing sends the validated fixture files and this card to an external
Hugging Face Dataset repository. Review the fixture provenance, licensing,
repository visibility, file allowlist, and projected storage cost before using
the explicit publication command. Tests and setup scripts never publish.
